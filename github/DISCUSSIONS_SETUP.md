# GitHub Discussions

Discussions are enabled. GitHub initialized these categories:

- Announcements
- General
- Ideas
- Polls
- Q&A
- Show and tell

Suggested use:

- **Announcements:** maintainer notices only.
- **General:** project questions and collaboration.
- **Ideas:** safe experiment proposals with stop conditions.
- **Q&A:** source and evidence questions.
- **Show and tell:** reproducible host-side analysis or review.
- **Polls:** use sparingly; polls do not establish technical evidence.

No welcome post or public announcement was created during launch. Keep sensitive vulnerability details and private artifacts out of Discussions.
