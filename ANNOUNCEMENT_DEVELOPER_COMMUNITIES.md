# Developer community announcement draft (not posted)

PROJECT ZERO is an independent research project working toward a **software-only jailbreak for Nintendo Switch V2 / Mariko**, with the goal of running unsigned native homebrew without a modchip or hardware modification.

The primary target is Horizon OS 23.0.1. The central challenge is finding a reproducible entry point that is reachable from a stock console and can lead to native code execution. Existing Erista, Switch 2, and older-firmware exploits are not assumed to work on Mariko.

The project combines AI-assisted research, public-source analysis, host-side experiments, and observations from a stock console. Areas explored so far include the Wi-Fi Web Auth Applet, USB/MTP, Horizon services, and known Switch exploit research. No working Mariko software-only jailbreak or complete exploit chain has been demonstrated yet; the current reports describe observations and closed leads as well as unresolved questions.

We welcome Switch homebrew developers, reverse engineers, embedded developers, exploit researchers, and AI-agent builders who can contribute a credible entry-point hypothesis, exact compatibility analysis, reproducible experiment, or independent review.

The project is looking for progress toward a real stock-to-homebrew path—not just general security commentary or speculative exploit claims.
