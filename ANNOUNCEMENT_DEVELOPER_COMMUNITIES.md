# Developer community announcement draft (not posted)

PROJECT ZERO is publishing an evidence-first, AI-assisted investigation into software-only homebrew feasibility for Nintendo Switch V2 Mariko / T210B01 on HOS 23.0.1.

The project started as one independent researcher working with a Switch V2, a MacBook, and AI coding/research tools. It now contains sanitized phase reports, safe host-side experiments, read-only stock-interface observations, and a skeptical review workflow. The current conclusion is deliberately narrow: no reproducible Mariko 23.0.1 entry point has been demonstrated, and the physical console's SoC identity has not been independently verified.

We welcome review of source claims, compatibility scope, test methodology, privacy handling, and proposed safe experiments. Contributions should identify evidence class, exact versions, legal provenance, and limitations. No proprietary firmware, keys, payloads, secrets, or bypass instructions are accepted. The Phase 15/16 application is excluded from this repository.
