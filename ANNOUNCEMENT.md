# PROJECT ZERO community launch

**PROJECT ZERO is an independent, AI-assisted research effort asking a precise question: is there a reproducible software-only homebrew entry point for Nintendo Switch V2 Mariko on Horizon OS 23.0.1?**

The project began with one researcher, a Switch V2, a MacBook, and AI coding/research tools. We are publishing sanitized reports, small host-side experiments, and limited stock-console observations so the community can audit what was actually learned.

So far, we have not demonstrated a Mariko 23.0.1 entry point. A benign captive-portal page exercised ordinary web APIs; read-only MTP sessions behaved consistently apart from a storage identifier changing after the user restarted MTP; and the console's exact SoC identity remains unverified. Those are observations, not an exploit.

## LET'S USE THE POWER OF AI TO BREAK NINTENDO'S SOFTWARE SECURITY BARRIER

We invite reverse engineers, embedded developers, security researchers, AI-agent builders, and skeptical reviewers to help investigate responsibly. Bring public sources, reproducible experiments, exact compatibility claims, and counter-evidence. AI may speed up analysis, but every conclusion must remain source-grounded and independently checkable.

We do not seek firmware dumps, keys, payloads, console secrets, or instructions to bypass protections. The Phase 15/16 Homebrew app is deliberately not part of this public repository.
