# Original hypotheses and challenge plan

Generated 50 distinct, falsifiable prompts across 10 areas. These are generic synthetic-model hypotheses, not claims about Horizon OS or hardware. Every experiment must state its own contract before execution.

## Ten assumptions to challenge experimentally

1. **Independent valid operations commute.** Permute pairs declared independent; compare final states and emitted events, including injected failure paths.
2. **Close/release is idempotent.** Replay once and twice at every reachable lifecycle state; compare canonical outcomes and resource counts.
3. **Reset clears dependent state.** Build parent/child resource graphs; reset at each transition and assert no live child outlives its declared parent.
4. **Revocation reaches all aliases.** Duplicate/transfer capabilities in a model; revoke source; test every alias under each order.
5. **Failure leaves no partial side effects.** Inject failure after every modeled substep and compare with an explicit rollback/commit contract.
6. **Unknown message fields/enums are handled consistently.** Generate absent, unknown and boundary values; compare independent parsers and versions.
7. **Retry after timeout is equivalent to one execution when marked idempotent.** Model commit-before-lost-ack and retry schedules; compare state.
8. **Resource quotas are conserved across ownership change.** Transfer/duplicate/release and assert global totals equal per-owner accounting.
9. **Cancellation only occurs at public operation boundaries.** Inject cancellation at every internal modeled transition and look for pending work after terminal cancel.
10. **Version changes preserve documented invariants.** Run identical traces against two synthetic versions and check only explicitly declared compatibility properties.

These assumptions are prompts for model design. No evidence says the real platform promises them. A model must cite a public contract before a result can be connected to a real interface.
