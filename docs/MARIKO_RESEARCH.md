# Mariko research scope

This project asks whether a stock Switch V2 / Mariko system on HOS 23.0.1 has a reachable software-only route to unsigned homebrew. A useful lead must address **reachability before homebrew**, hardware scope, firmware scope, privilege boundary, reproducibility, and evidence provenance.

Public research on Erista, Switch 2, older firmware, SDK libraries, or already-running homebrew is not automatically applicable. For every claim, record the full chain and identify exactly which stages were reproduced on which target. The current record contains no reproduced Mariko/HOS 23.0.1 chain. Exact SoC identity and target HOS executables remain unavailable in the evidence archive.
