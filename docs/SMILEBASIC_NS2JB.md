# ns2jb / SmileBASIC claim notes

The project reviewed public ns2jb material and recorded an author statement indicating some Switch 1 testing, while the released demo material is scoped to Switch 2. The public material reviewed did not establish a full Switch 1 exploit chain, exact Switch 1 model/SoC, HOS compatibility range, independent reproduction, or Mariko/T210B01 support on HOS 23.0.1.

Treat the report in `reports/EVIDENCE_REGISTER.md` and Phase 4/5 records as a dated source review, not a current compatibility guarantee. Recheck the original author's current publication and repository before making a new claim. Do not present Switch 2 support as Switch 1 support.
