# ns2jb / SmileBASIC compatibility review

PROJECT ZERO reviewed public ns2jb material because it may appear relevant to the broader goal of a software-only Switch jailbreak. The reviewed material includes an author statement indicating some Switch 1 testing, while the released demo is scoped to Switch 2.

The public material reviewed did not establish a complete Switch 1 exploit chain, exact Switch 1 model/SoC, HOS compatibility range, independent reproduction, or Mariko/T210B01 support on HOS 23.0.1.

Treat the report in reports/EVIDENCE_REGISTER.md and the Phase 4/5 records as a dated source review, not a current compatibility guarantee. Recheck the original author's current publication and repository before making a new claim. Switch 2 support must not be presented as Switch 1 / Mariko support.
