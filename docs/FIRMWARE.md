# Firmware scope

The target version is Horizon OS **23.0.1**, as reported by the console owner and recorded during the physical-device workflow. The project has no authenticated firmware image, system-module binary, NPDM, or console dump for that version. Therefore the exact internal implementation of HOS 23.0.1 was not statically analyzed.

Version claims should include a direct device observation or a primary source. Do not infer firmware compatibility from a library, SDK, application, or another Switch model. Public update/advisory references are collected in the phase reports and vulnerability database; historical fixed versions do not imply a currently usable entry point.
