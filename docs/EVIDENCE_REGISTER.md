# Evidence register entry point

The canonical detailed, privacy-scrubbed register is [reports/EVIDENCE_REGISTER.md](../reports/EVIDENCE_REGISTER.md). Its classes distinguish physical-console observations, host tests on public source, public documentation, model outputs, hypotheses, and narrowly falsified claims.

Read the method and limitations before reusing a result. In particular, a user-reported version and a USB VID/PID do not authenticate the SoC; a successful web API call does not prove a security boundary was crossed; and a changed Storage ID is not a vulnerability without a demonstrated impact.
