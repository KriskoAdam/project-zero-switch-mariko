# Redistribution notes

This public copy excludes the entire local native Homebrew application and all associated source/build outputs. It excludes third-party tool distributions, virtual environments, caches, Nintendo firmware/dumps, keys, and private credentials.

The libnx excerpts in `references/libnx/` include the source license notice. A devkitPro/newlib object file, its disassembly, and a reconstructed source file were omitted because redistribution rights were not established. The historical reports retain the artifact hash and explain that omission; a hash is not a substitute for permission to redistribute the object.

Review every new binary, capture, and generated artifact for ownership, privacy, and license before adding it.
